导出静态网站

将当前编辑的内容生成一个完整的 HTML 文件，可以直接上传到 GitHub Pages 或任何静态托管平台。

导出说明

  • 导出的文件包含所有当前编辑的内容
  • 无需后端，纯静态 HTML，任何平台都能托管
  • 包含完整的样式和交互效果
  • 导出后如需再次修改，需要重新导出并上传

上传步骤

  1. 1. 点击上方按钮下载生成的 index.html
  2. 2. 打开你的 GitHub 仓库
  3. 3. 上传 index.html 覆盖旧文件
  4. 4. 等待 1-2 分钟，访问你的网站查看效果
