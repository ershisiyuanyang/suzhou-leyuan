## 一、系统简介

投流预算管理是一个**网页工具**，用于抖音本地推投流的预算排布、每日填报与报表复盘，解决"预算怎么分、每天花了多少、月底还剩多少、哪个计划划算"的问题。

**核心能力一览**

| 能力 | 说明 |
| --- | --- |
| 月度预算排布 | 设定当月总预算，按周策略自动分配到每天、每个计划，自动凑整 100 元 |
| 一键重排 | 已实际发生与手动调整过的日期不被动，只重排剩余日期 |
| 每日填报 | 日历点选任意一天，填报该日各计划的预算 / 实际消耗 / GMV / 曝光量，可加备注 |
| 实际账户余额 | 独立于月度预算，跨月延续；可手动改（充值、计划外变动），月末一键结转 |
| 报表复盘 | 按日 / 按分类 / 按计划汇总，含 ROI、达成率、备注，一键导出 Excel |
| 计划管理 | 计划增删改、分类（通投短视频 / 通投搜索 / 直播 / 门店全域）、报表排序自定义 |
| 多账号权限 | 所有访问者需账号密码登录；管理员可创建用户并授予查看 / 报表导出 / 修改权限 |
| 操作日志 | 记录关键操作（时间、内容、操作人），便于追溯 |

**技术架构（了解即可）**

- 纯静态网页（HTML + CSS + JavaScript），无服务器代码
- 数据存储在**腾讯云 CloudBase** 云数据库（NoSQL），网页直接读写
- 同一份数据，本地预览和线上访问完全一致，关掉页面数据不丢

## 三、账号与权限

### 权限模型

| 权限 | 作用 | 说明 |
| --- | --- | --- |
| 查看 | 登录进入系统，查看全部数据 | 登录的**基础权限**，未勾选则无法登录 |
| 报表导出 | 使用报表页"导出 Excel"按钮 | 可看不可改，适合汇报用 |
| 修改数据 | 编辑预算 / 填报 / 计划 / 账户余额等一切数据 | 可单独授给指定的执行人员 |

- **管理员 admin**：拥有全部权限，可管理所有用户、修改自己密码
- 权限可自由组合（如"查看 + 报表导出"、"查看 + 修改数据"、"三项全选"）
- 无"修改数据"权限的账号登录后，写控件自动隐藏，核心写操作也会被拦截（双重防护）

### 用户管理（仅管理员可见）

「👥 用户管理」页：

1. **创建用户**：输入用户名、初始密码（至少 4 位），勾选权限（查看默认勾选），点「+ 创建用户」
2. **编辑权限 / 重置密码**：点用户行"编辑"按钮，勾选权限，重置密码处留空则不改
3. **删除用户**：点"删除"；**admin 内置账号不可删除**
4. 用户名创建后不可改名（删除重建即可）

### 修改密码 / 锁定

- 右上角「修改密码」：管理员修改自己的登录密码
- 右上角「锁定」：退出登录，返回登录页（离开工位时建议锁定）

## 四、功能使用说明

### 4.1 📊 总览

- 顶部卡片：**本月总预算 / 已消耗 / 剩余余额 / 剩余天数·日均可用 / 综合 ROI（GMV÷消耗）/ 总曝光量**
- 上方可切换月份（下拉框）
- 近 14 天「预算 vs 实际」走势图
- 本月计划明细表：各计划预算、实际、达成率、GMV、ROI、曝光、剩余，顺序与报表页自定义排序一致

### 4.2 📅 月度排布

#### （1）当月总预算与备注

- 「月度预算排布」面板：输入当月总预算（元）＋ 备注，点「保存月度预算」
- 总预算用于自动排布与各统计口径，与账户实际余额无关

#### （2）实际账户余额（跨月延续）

- 顶部「💰 实际账户余额」：**当前账户真实余额**，独立于月度预算
- 充值、计划外扣款等情况直接修改并「保存余额」
- 「同步本月消耗」：月底使用，自动从账户余额中扣减本月实际消耗，余额结转到下月
- **预估月末余额 = 账户余额 − 剩余待花预算（本月总预算 − 已消耗）**，即假设剩余预算全部花完后的账户结余

#### （3）按余额重排剩余日期（一键重排）

- 「剩余可排预算」自动计算：`当月总预算 − 实际已发生 − 已锁定日期预算`，只读
- 勾选项：
  - **周策略**（默认开）：周五 / 周六 / 周日为冲锋日预算上浮，周一至周四略低
  - **含今天**（默认开）：今天是否参与重排
- 规则：
  - **不改变已发生日期的预算**（含当日）
  - **不覆盖手动调整过的日期**（锁定保护）
  - 每日预算凑整至 100 元
  - 计划明细按"前一日实际消耗（优先）或预算"的比例预设，每个计划凑整至 100 元
  - 之后月份同样适用

#### （4）每日预算日历（每日填报入口）

- 日历中点击任意日期，弹出该日编辑面板
- 每个计划可填报：**预算 / 实际消耗 / GMV / 曝光量 / 备注**
  - 预算列：上下调控键以 **100 元** 为步进
  - 实际 / GMV / 曝光量：无调控键，直接输入
- 面板顶部显示**当日各计划预算合计**
- 手动改动任一行预算后，该日自动标记**锁定**（重排不会覆盖它）；「锁定」键可手动锁定 / 解锁
- 备注列用于记录异常情况（如"当天改价导致消耗偏高"），会记入报表每日汇总的备注列
- 保存后即写入云端，随报表 / 统计自动汇总

### 4.3 📋 投流计划管理

- 「+ 新增计划」：计划名称 ＋ 分类（通投短视频 / 通投搜索 / 直播 / 门店全域）＋ 备注（选填）
- 表格内可直接改名称 / 分类 / 备注 / 状态（启用 / 停用）
- 改多行后点「一键保存（N）」批量落库（黄色高亮 = 有未保存改动）
- 停用的计划不参与统计与排布

### 4.4 📈 报表复盘

1. 选日期范围（起 / 止），点「生成报表」
2. 顶部卡片：期间预算 / 实际 / GMV / 综合 ROI / 总曝光 / 达成率·日均消耗
3. **每日汇总**：逐日预算、实际、GMV、ROI、曝光、差额、达成率、备注（含走势图）
4. **按分类汇总**：四类计划横向对比
5. **按计划汇总**：每个计划的预算、实际、达成率、GMV、ROI、曝光、日均消耗
6. **投流计划排序**：拖动每行左侧手柄（⠿）调整报表展示顺序，松手自动保存，报表 / 总览默认按此排列
7. **导出 Excel**：一键导出当前报表（含明细与备注列），用于汇报或存档
   - 需要账号具备"报表导出"权限

### 4.5 📜 操作日志

- 记录关键操作：时间、操作内容、详情、操作人
- 顶部「刷新」按钮手动刷新；默认展示最近 200 条

## 六、常见问题（FAQ）

**Q1：打开后还是旧界面 / 功能没更新？**
浏览器缓存了旧版。强制刷新：Mac `Cmd+Shift+R`，Windows `Ctrl+Shift+R`；或清除该站点缓存。

**Q2：双击 index.html 打开后提示"请用本地服务打开"？**
浏览器会拦截 `file://` 页面访问云端数据。请改用启动脚本或线上地址访问。

**Q3：本地预览 8090 端口打不开？**
端口可能被占用，启动脚本会自动顺延 +1，请以终端窗口提示的地址为准。

**Q4：管理员密码忘了怎么办？**
需联系维护人员在云端 `dbudget_settings` 中重置 `accessPwdHash`（页面无自助找回功能）。

**Q5：某天的预算被重排改掉了？**
不会。手动改动过的日期会自动锁定，一键重排跳过锁定日；若仍被改，检查该日是否处于"锁定"状态（日历面板锁图标）。

**Q6：游客能不能直接看？**
不能。所有访问者都必须用管理员分配的账号密码登录，没有游客通道。

**Q7：账号提示"无查看权限"无法登录？**
该账号未被勾选"查看"权限，请联系管理员在「👥 用户管理」中编辑该用户。

**Q8：导出 Excel 按钮点了没反应？**
账号缺少"报表导出"权限，请联系管理员开通。
